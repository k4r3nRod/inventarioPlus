                    ENCRIPTACIÓN DE CONTRASEÑAS CON BCRYPT - ACTUALIZADO
===============================================================================

¿QUE PERMITE QUE LA CLAVE SE GUARDE ENCRIPTADA?

En el proyecto actualizado, las contraseñas se guardan encriptadas usando BCrypt:

```java
// Encriptar la contraseña con BCrypt antes de guardarla
String claveEncriptada = PasswordEncoder.encode(passwordOriginal);
usuario.setPassword(claveEncriptada);
```

LO QUE PERMITE LA ENCRIPTACIÓN CON BCRYPT:
-----------------------------------------

1. CLASE PasswordEncoder CON BCRYPT
   - Utiliza BCryptPasswordEncoder de Spring Security
   - Genera salt automáticamente para cada contraseña
   - Usa algoritmo Blowfish (mucho más seguro que MD5)

2. FLUJO DE ENCRIPTACIÓN:
   1. Usuario ingresa: "admin123"
   2. El servicio llama: PasswordEncoder.encode("admin123")
   3. Se genera hash BCrypt: "$2a$10$N9qo8uLOickgx2ZMRZoMye..." (60 caracteres)
   4. Se guarda en BD: "$2a$10$N9qo8uLOickgx2ZMRZoMye..."

3. EN LA BASE DE DATOS:
   - El campo password VARCHAR(255) almacena el hash BCrypt
   - Nunca se guarda la contraseña original
   - Salt único para cada contraseña
   - Algoritmo resistente a ataques rainbow table

4. PARA VALIDAR LOGIN:
   - Se toma la contraseña ingresada
   - Se usa: PasswordEncoder.matches(passwordIngresado, hashAlmacenado)
   - BCrypt maneja internamente la validación con salt

EJEMPLO PRÁCTICO:
----------------
Contraseña original: "admin123"
Hash BCrypt guardado: "$2a$10$N9qo8uLOickgx2ZMRZoMye/IlPJq.L3pnllRCf//CO1SfM.mjuQea"

NOTA DE SEGURIDAD:
-----------------
MD5 ya no es considerado seguro para contraseñas debido a:
- Vulnerabilidades conocidas
- Facilidad para generar colisiones
- Rapidez para realizar ataques de fuerza bruta

VENTAJAS DE BCRYPT (SISTEMA ACTUAL):
-----------------------------------
✅ Algoritmo moderno y seguro
✅ Salt automático único para cada contraseña
✅ Resistente a ataques rainbow table
✅ Factor de costo ajustable (actualmente 10)
✅ Ampliamente recomendado por expertos en seguridad
✅ Soportado nativamente por Spring Security
✅ Lento por diseño (previene ataques de fuerza bruta)
